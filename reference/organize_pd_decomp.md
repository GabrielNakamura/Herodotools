# Auxiliar to organize output from PD decomposition function

Auxiliar to organize output from PD decomposition function

## Usage

``` r
organize_pd_decomp(list1.decomp, list2.treetable)
```

## Arguments

- list1.decomp:

  data frame with PD components

- list2.treetable:

  tibble with edge partition for each community

## Value

A list object with decomposition of PD
