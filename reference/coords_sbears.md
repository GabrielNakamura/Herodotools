# Spatial coordinates of sites

Spatial coordinates containing longitute and latitude of 46 sites

## Usage

``` r
coords_sbears
```

## Format

A data frame object with 46 rows and 2 columns:

- longitude:

  Numeric. Longitude of each site in decimal degrees

- latitude:

  Numeric. Latitude of each site in decimal degrees
