# Output from `evoregion` function with classification of 732 assemblages

Object containing a list with two objects:

- \$PCPS:

  A list containing eigenvectors from PCPS analysis

- \$Cluster_Evoregions:

  A vector containing the groups of each assemblage

## Usage

``` r
regions
```

## Format

An object of class `evoregion` of length 2.
